# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in REAPER OS, **do not open a public issue**. Instead, please report it responsibly by emailing:

**security@reaper-os.dev** (or via private GitHub issue if available)

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if applicable)

We will respond to security reports within 48 hours and work with you to resolve the issue before public disclosure.

## Security Best Practices

When using REAPER OS:

1. **Keep updated**: Regularly update to the latest version
2. **Audio interfaces**: Verify drivers from official sources
3. **VST plugins**: Download from trusted repositories
4. **Network audio**: Use Dante/AES67 on trusted networks only
5. **Credentials**: Never commit API keys or tokens
